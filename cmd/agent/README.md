# Laptop metrics agent

The native Windows/Linux agent exposes `GET /metrics` with timestamped whole-machine CPU, memory, disk, network counters, uptime, and optional temperature. Windows uses native APIs and omits unsupported temperature. It also exposes `GET /health` and `GET /identity`. Run `go run ./cmd/agent` or the Windows executable. Set `AGENT_ADDR` to a private LAN bind address when the controller runs on the Pi; the Windows launcher sets it to `0.0.0.0:8081`, with firewall rules restricted to the Pi. `METRICS_DISK_PATH` defaults to `/` on Linux and the Windows system drive on Windows. [Windows/Pi setup and tests](../../docs/windows-pi-setup.md).
